# Agent rules for this repository

Before doing anything in this repository, read and follow
`docs/orchestration/BUILDER_RULES.md`. It is the full rule set.

If you are asked to "do the next task": take the lowest-numbered file in
`docs/handoffs/todo/` and do only that one. If `todo/` is empty, say so and
stop. If `docs/handoffs/doing/` already holds a task, finish that one instead.

The rules that matter most:

- Work only on the task file you were given, from `docs/handoffs/`.
- No AI attribution anywhere: no `Co-Authored-By` lines and no "generated by"
  notes in commits, pull requests, comments or file headers.
- Never commit audio files or local config. Never delete user recordings or
  projects.
- Never push. Never change a decision in `docs/ARCHITECTURE.md`; write
  disagreements as open questions in your status report.
- Run every "Done when" check and paste the real output. A failed check is
  reported as failed.
